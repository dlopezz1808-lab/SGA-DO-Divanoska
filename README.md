## 📋 Descripción del Proyecto

El Sistema de Gestión Académica (SGA-DO) es un backend de consola diseñado para modernizar los procesos administrativos de DiplomadosOnline.com. El sistema permite:

- Registro de alumnos y profesores
- Gestión de calificaciones (máximo 3 notas)
- Evaluación polimórfica por tipo de programa (Curso, Diplomado, Bootcamp)
- Función Deshacer (Ctrl+Z) con estructura LIFO
- Generación de certificados con estructura FIFO
- Persistencia en archivos de texto plano (.txt)

El proyecto ha sido implementado en **Python, Java y C++** para evaluar el rendimiento y las características de cada lenguaje.
